# NoType 使用手册

## 首次安装

下载 Release 中的 Apple Silicon ZIP，解压后把 NoType.app 拖到 `/Applications`，从这个固定位置启动。系统要求 macOS 14+，Liquid Glass 需要 macOS 26+。

当前版本未经过 Apple 公证。确认文件来自项目官方 Release 并核对 SHA256 后，如果 macOS 阻止启动，可在“系统设置 → 隐私与安全性”查看系统是否提供“仍要打开”。具体提示随系统版本及设备管理策略而异。无需关闭 Gatekeeper、SIP 或全局安全策略。

## 权限

| 权限／设置 | 用途 | 位置 |
| --- | --- | --- |
| 麦克风 | 录制主动发起的口述 | 隐私与安全性 → 麦克风 |
| 辅助功能 | 向原输入框粘贴文字 | 隐私与安全性 → 辅助功能 |
| 语音识别 | 仅 Apple 引擎需要 | 隐私与安全性 → 语音识别 |
| 听写 | Apple 引擎可用性依赖系统配置 | 键盘 → 听写 |

macOS 的“控制此 Mac 并访问数据”提示对应辅助功能能力。NoType 通过该权限输入文字；权限开关需要本人设置。更新时保持应用路径固定。若更换了签名，移除旧条目，再添加当前 `/Applications/NoType.app`。不要随意重置其他应用的系统权限。

## 日常口述

1. 在微信、浏览器、编辑器等目标应用中放好光标。
2. 按 `⌃⌥Space` 开始录音；再次按下结束。录音最长 5 分钟。
3. 底部浮窗显示识别、整理与输入状态，成功输入后关闭。
4. Codex 整理期间可以点“立即使用原文”。如果目标输入框改变，应用会回退复制，请自行确认后粘贴。

在设置中点“修改快捷键”，直接按新组合；至少包含 Command、Option 或 Control，Esc 取消。系统或其他软件占用组合时换一个快捷键。

## Whisper

先安装 Homebrew，下载本仓库源码，在源码目录运行 `bash scripts/install-whisper.sh`。脚本下载 small 多语言模型约 465 MiB，并核验固定 SHA256。脚本不会自动安装 Homebrew。

将脚本输出的 `whisper-cli` 路径和模型路径填进设置。Apple Silicon 上常用引擎路径为 `/opt/homebrew/bin/whisper-cli`；模型为 `~/Library/Application Support/NoType/Models/ggml-small.bin`。已有兼容的 whisper.cpp 模型也可手动选择。

Whisper 使用本机计算资源，不消耗云端语音 API 额度。只开本地识别且关闭 Codex 整理时，无需向这两类云端服务发送口述内容。

## Apple 设备端识别

开启系统听写和相应语言，授予语音识别权限，再选择 Apple。NoType 请求设备端识别；所选语言缺少设备端能力时会报错，不会静默上传到其他语音服务。若提示 Siri/Dictation disabled，请检查系统听写设置；仍不可用可使用 Whisper。

## 云端语音 API

### 千问

1. 选择“云端 API · 自定义”。
2. 协议选择“千问 ASR Flash · 音频 Chat 接口”。
3. 按自己 Key 的地域选择预设：

| 地域 | Base URL |
| --- | --- |
| 北京 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 新加坡 | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1` |

4. 模型填写 `qwen3-asr-flash` 或服务商确认兼容且账号可用的型号。
5. 输入自己的 Key，点击保存。切换地域／地址／协议后，需要为对应接口重新保存 Key。
6. “用内置示例测试转写”会上传约 5 秒英文示例，消耗自己的服务商额度；不会使用麦克风或调用 Codex。成功后显示耗时。

接口自动补齐 `/chat/completions`，以 Base64 WAV 上传。**不支持 `*-filetrans` 异步轮询模型，也不支持 `*-realtime` WebSocket 模型。** 不能只替换模型名来切换不同协议。

### 其他服务商

选择“通用转写 · multipart /audio/transcriptions”，填写服务商的 HTTPS 地址、模型与 Key。接口必须支持 Bearer 鉴权、multipart 文件上传和 `{"text":"转写文字"}` JSON 响应。不支持自定义签名、任意 HTTP 请求模板或其他 WebSocket 协议。

### 等待或失败

测试成功只说明该次请求可用，不保证后续延迟。实际口述会在录音结束后上传整段音频。转换最多 15 秒，网络请求最多等待 45 秒；上传不超过 25 MiB，供应商可能限制得更严格。无自动付费重试。

- 401/403：检查 Key、地域和模型权限。
- 429：检查额度或限流。
- 超时：检查网络及代理线路、服务商状态，可手动重试或改用 Whisper。
- 转写失败：实际录音暂存，可重试或放弃。开始新录音或退出会清理应用拥有的暂存录音。

## Codex 文字整理

按 [官方文档](https://developers.openai.com/codex/cli/)安装 Codex CLI 并使用 ChatGPT 登录。NoType 设置中选择可执行文件，点击“刷新模型”。列表来自这台电脑的 CLI；自动模式从实际可选模型中推荐适合短文本的较快型号，也可手选。NoType 不保证某个账号能用特定型号。

| 模式 | 行为 |
| --- | --- |
| 自然表达 | 删除无意义语气词／找词过程、合并赘述、按最后明确说法修正自我纠正、整理标点 |
| 忠实原文 | 保留措辞，主要修正标点、明显错字和词库专有名词 |
| 邮件与消息 | 整理成适合发送的简洁正文，不补造收件人／承诺 |
| 翻译成英文 | 保留原意与专有名词，输出英文正文 |

原始转写在左侧保留；右侧显示最终文字。下方“已整理”包含模型和耗时；“未完成整理 · 使用转写原文”表示回退，不能理解成模型成功优化。超过 20 秒时可按设置自动使用原文，也可随时主动跳过。

个人词库每行一个词，仅用于整理提示，不能保证所有专有名词识别正确。数字、名字和重要事实请在发送前核对。

## 历史和统计

历史保存文字，不保存成功录音；支持搜索、编辑、复制、导出与删除。关闭历史保存不会删除已有条目。导出文件可能包含隐私，请自行保管。

统计来自保存的成功口述历史，包括字数、按录音时长计算的平均速度、口述时间、活跃天数和每日热力图。导入音频、手动输入和反复整理不重复计算口述量；删除历史会影响统计。
