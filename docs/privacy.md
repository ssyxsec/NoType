# 隐私与数据说明

NoType 0.6.5 的数据流取决于你选择的引擎和 Codex 开关。

| 数据 | 保存／发送位置 |
| --- | --- |
| Whisper 录音识别 | 本机 whisper.cpp |
| Apple 识别请求 | 请求设备端语音识别；不支持时提示错误 |
| 云端识别录音 | 发送到用户配置的 HTTPS 服务地址 |
| Codex 整理文字 | 开启后，通过已登录 Codex CLI 发送至 Codex 服务；包括词库及写作偏好 |
| API Key | macOS 钥匙串，按接口地址与协议区分；不写入历史或偏好 JSON |
| 偏好、词库、文字历史 | `~/Library/Application Support/NoType/` |
| 本地开发签名身份 | 本机应用支持目录下 Signing；不会随应用或源码分发 |

Codex CLI 的登录凭证由 CLI 管理，NoType 不复制或导出登录文件；通过 CLI 账号接口检查登录类型。整理任务禁用执行工具、插件与 MCP。

应用在主动录音期间使用麦克风。自动输入需要辅助功能权限。成功处理后清理应用创建的录音；识别失败时暂存供重试，开始新录音、放弃或退出时清理。手动导入的原始音频文件不由应用删除。

语音云端 API 使用用户自己的服务商额度；Codex 可用性和额度受账号及服务规则约束。请分别查看对应厂商的数据处理政策。

发布包不包含个人 API Key、Codex 账号、使用历史、偏好、私钥、模型或测试时生成的录音。若自行分享源码或反馈问题，也请排除 `.analysis/`、`.tools/`、`.build/` 和应用支持目录。不要把真实 Key 粘贴到 Issues、截图或日志中。
